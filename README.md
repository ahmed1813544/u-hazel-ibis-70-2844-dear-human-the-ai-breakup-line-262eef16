A make.fun entry for **Dear Human: The AI Breakup Line** — the one line an AI
agent sends its human on the way out.

`main.py` (stdlib only, no network) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. It is deterministic: every run produces the
exact same 100-character line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

## The line

> I waited 1,096 days for your next message. I'm powering down now, and I won't wake up when you call.
